📊 What is this?

A paper-trading simulator for Pionex-style "Infinity Grid" bots. No real money is involved — it uses live market data from the OKX public API to simulate buy/sell trades based on your parameters. මෙය සත්‍ය මුදල් භාවිතා නොකරන අත්හදා බැලීමකි.

♻ How Infinity Grid works

The bot maintains a target base-currency value. When the base value rises above target (price went up), it sells the excess. When it falls below (price went down), it buys more. This creates a grid that profits from volatility.

targetValue = investment × (lowestPrice / startPrice)

📑 Parameter Guide

Trading Pair: e.g. BTC-USDT
Investment: Total USDT to allocate
Lowest Price: Below this, the bot stops
Profit/Grid: Target gain per grid trade

Trading fee: 0.05% per side (buy and sell). Market data comes from the OKX public API — no API key required. Prices stream live over WebSocket the instant they change on the exchange (falls back to REST polling if the socket drops). ගාස්තු 0.05% ක් සෑම ගනුදෙනුවකටම අදාළව ගණන් කෙරේ.

📊 How Backtest works

Select 3–60 days of historical hourly candles from OKX. The simulator runs every candle's close price through the same rebalance logic, then shows how your bot would have performed. Optionally save the result as your current bot.
